# one_page_template

一頁式網頁（One-page website）模板專案。

本 repo 作為建立單頁網站的起點：適合 landing page、活動頁、產品介紹、個人作品集等只需一個頁面即可呈現完整內容的場景。複製或 fork 此專案後，依需求調整版型、文案與樣式即可快速上線。

## 用途

- 快速產出一頁式網站，無需多頁路由
- 作為團隊或個人專案的統一模板
- 後續可在此基礎上擴充區塊（Hero、特色、CTA、聯絡表單等）

## 開始使用

1. 複製或 clone 此 repository
2. 依專案技術棧安裝依賴（若已加入）
3. 修改內容與樣式
4. 部署至靜態托管或自有主機
